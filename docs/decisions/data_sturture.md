## tech protocal
    ทำยังไงก็ได้ ให้ esp node หลักข้อมูลมาได้ แล้ว ก็ตัว server ไปสั่ง esp node หลัก เพื่อส่งไปที่ node ย่อยๆ เพื่อควบคุม relay น้าไฟ ได้

    - ใน pakgate ที่ส่ง จะมี UUID และ ตอนรับจะ รับ CMD ผ่าน UUID ถ้าตรงอันไหน ตัวนั้น ทำ

    - คล้ายๆ DIGITAL TWIN การแสดง อาจากได้ 3D แต่กราฟ การดู ข้อมูลนั้น อยากดู เป็น กราฟ แยกกัน

    - hardware รุ่นตลาด กับ hardware รุ่นคอนโด นั้น formatการส่ง ต่างกัน

## software

โดนระบบจะแยก ผู้ใช้ ออกเป็น สามรูปแบบ สี่ส่วน

ตลาด
- ผู้ใช้ ที่เป็น เจ้าของ
    - ดูได้ว่า ไฟวันนี้ เป็นยังไง บ้าง ใช้ อะไรไปเท่าไร แนวโน้ม กราฟ การเงิน อื่นๆ ที่ควรมี
    - animation ให้เห็น เป็น ล๊อกๆ สามารถแยกโซนได้ ชั้งชื่อ โซนได้ อาจะเป็น แถวๆ
    - น้ำไฟตั้ง เรท ได้
    - กด เปิด ปิด น้ำไฟได้เอง
    - ตั้งรอบการตัดบิลได้
        - ออกวันไหน ของเดือน
        - ส่งบิลไปที่ accout ของ ผู้เช่า ให้ผู้เช่า แนบสลิป แล้ว ให้เจ้าของตลาด กด เปลี่ยน สถานะ จากค้างจ่าย ไฟเป็น จ่ายแล้ว
    - กำหนดได้ว่า จ่ายได้ เรทสุด กี่วันจากวัน กำหนดจ่าย จ่ายเรทกว่านั้น ก็ตัด auto 
        - แล้วก็ สามารถ เปิดให้ใช้ได้ ถ้าเจ้าของคุยแล้ว ก็สามารถให้ เจ้าของตลาด เปิด ให้ใช้ได้ ก็จะเป็น state ที่ค้างจ่ายแต่ เจ้าของ เปิดให้ใช้ได้

- ผู้ใช้ที่เป็น ผู้เช่า
    - ผู้เช่าจะให้ ID กับ pass กับเจ้าของแผงลอย โดยรหัสจะ เป็น
        - ID: market_name@xxxxxx: pass:xxxxxxx
    - animation ให้เห็น เป็น ล๊อกๆ สามารถแยกโซนได้ ชั้งชื่อ โซนได้ อาจจะเป็น ตึกๆ 
    - UI ใช้ไฟ น้ำ ไฟกี่บาท มีบิลมั้ย


คอนโด ห้องเช่า
