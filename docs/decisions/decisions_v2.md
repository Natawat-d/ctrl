# ✅ การตัดสินใจรอบ 2 (20 ข้อ) — ต่อยอดจาก decisions.md

## Platform & โครงสร้าง
1. **บัญชีเจ้าของ:** สมัครเอง + **ยืนยัน Email** + ติ๊กยอมรับเงื่อนไข (ร่างให้) **และ** admin สร้าง/แก้ไขได้
2. **Platform admin:** ลิสต์ไซต์ + จัดการบัญชี (ไม่ต้อง dashboard สถิติเต็ม)
3. **1 เจ้าของ → หลายไซต์** (ตลาด+คอนโดหลายที่)
4. **คอนโด:** ทำพร้อมตลาดเลย

## คอนโด + รหัสผู้เช่า
5. **ID ผู้เช่า = `slug@รหัสล็อก`** (ตลาด/หอมี slug ไม่ซ้ำ ผูก market_name)
6. **คอนโด: ตึก → ชั้น → ห้อง** (3 ระดับ; unit มี field ตึก/ชั้น)
7. **ใช้ collection เดียวกัน** (type=condo, zone=ตึก, unit=ห้อง)
8. **คอนโดวัด ไฟ+น้ำ ทุกห้อง**

## ค่าเช่า & ค่าธรรมเนียม
9. **บิลแยกบรรทัด:** ค่าไฟ + ค่าน้ำ + ค่าแผง/ห้อง + **ค่าส่วนกลาง**
10. **ค่าส่วนกลาง: กำหนดต่อห้องได้**
11. **Override รายห้องได้ทุกช่อง** — เรทน้ำ-ไฟ + ค่าเช่า + ส่วนกลาง + วันจ่าย/ผ่อนผัน/ค่าปรับ
12. **วันจ่าย/ผ่อนผัน/ค่าปรับ:** default ระดับตลาด + override รายห้องได้

## Login / บทบาท / แจ้งเตือน
13. **หน้า login มีปุ่ม mock role** (admin/เจ้าของ/ผู้เช่า) เชื่อมบัญชี demo จริง
14. **3 บทบาทเท่านั้น:** platform_admin / owner / tenant (ไม่มี staff)
15. **ผู้เช่า login: user/pass** (slug@ห้อง)
16. **แจ้งเตือน LINE/Email ทำเลย** (บิลใหม่/ใกล้ตัด/ตัดแล้ว) + ใช้ระบบเดียวกับ email verify

## UI/UX (อิง ref_UI = FOODLY)
17. **Accent แดง/coral** (brand) — เก็บเขียว/แดงเป็นสีสถานะแยก
18. **Top nav + ไอคอน** (pill active) — เลิก sidebar
19. **การ์ดลอยมุมโค้งบนพื้นเข้ม** (app panel เดียวกลางจอ)
20. **โปร่ง การ์ดใหญ่ ไอคอนเด่น** สไตล์ FOODLY

## แผน build (เฟส)
- **A. UI re-skin** → globals ใหม่ (dark bg + floating panel + top nav + red accent) + reskin ทุกหน้า + ปุ่ม mock-role login
- **B. ค่าธรรมเนียม** → ค่าส่วนกลาง + override รายห้องทุกช่อง (แก้ billing + settings + schema unit.rate/fees/billing override)
- **C. คอนโด** → type=condo, ตึก→ชั้น→ห้อง, seed คอนโด demo
- **D. บัญชีเจ้าของ** → signup + email verify + terms + admin จัดการ
- **E. แจ้งเตือน** → notifier (Email SMTP + LINE) + hooks (บิล/ใกล้ตัด/ตัด)
- **F. Platform admin portal** → ลิสต์ไซต์ + จัดการบัญชี
