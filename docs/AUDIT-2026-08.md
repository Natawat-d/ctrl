## 🔴 CRITICAL (ต้องแก้ก่อนขึ้นจริงเด็ดขาด)

### ✅ SEC-1 · [แก้แล้ว 2026-08-04] ปลอม token เป็น admin ได้ (ยึดทั้งระบบ)
`lib/auth.js` — เดิม `JWT_SECRET || "dev-secret-change-me"`
**แก้แล้ว:** `getSecret()` fail-closed — production ที่ไม่มี `JWT_SECRET` จะ throw (เช็ค lazy ตอนใช้ token ไม่ใช่ตอน import กัน build พัง). VPS ตั้ง JWT_SECRET จริงแล้ว · **ยืนยัน production**: token ปลอมเซ็นด้วย default secret → 401 ทุก endpoint (เดิม 200 + password)

### ✅ SEC-2 · [แก้แล้ว 2026-08-04] owner ยึดบัญชี admin/owner อื่นได้ (account takeover)
`app/api/users/[id]/route.js` PATCH/DELETE
**แก้แล้ว:** lookup ผ่าน `tenantFilter` + `guardTarget()` ห้าม owner แตะ role ที่ไม่ใช่ tenant_user (403). รีเซ็ตรหัสผู้เช่าตัวเองยังทำงาน · เทส: owner PATCH admin → 404, display_name admin ไม่เปลี่ยน

### ✅ SEC-3 · [แก้แล้ว 2026-08-04] IDOR: ผู้เช่าเห็นบิล/ห้อง/มิเตอร์ของทั้งอาคาร
`controllers/resource.js` crud.get/list
**แก้แล้ว:** `occupantScope()` — tenant_user เห็นเฉพาะ units ที่ตัวเองอยู่ (units: occupant_user_id / bills·meters·readings: unit_id ∈ ห้องตัวเอง / collection อื่น: deny). เทส: a-101 GET /api/bills = เฉพาะ 6 ใบตัวเอง, GET ห้องคนอื่น → 404, /api/zones → ว่าง · เจ้าของเห็นทั้งหอเหมือนเดิม

### ✅ SEC-4 · [แก้แล้ว 2026-08-04] /api/ingest เปิดโล่ง (ปลอม telemetry → ปั่นบิล)
`app/api/ingest/route.js`
**แก้แล้ว:** fail-closed — production ไม่มี `INGEST_KEY` → 503 · มี key → ต้องส่ง X-Ingest-Key ตรง. VPS ตั้ง key แล้ว · **ยืนยัน production**: ingest ไม่มี key → 401 + บันทึก audit การ ingest

### ✅ BILL-1 · [แก้แล้ว 2026-08-04] มิเตอร์ถูกเปลี่ยน/reading เบาบาง → บิลค่าน้ำ-ไฟ = 0 ทั้งเดือน
`controllers/billingController.js` — เดิม usage = last−first ในเดือน, `d<0?0`
เปลี่ยนมิเตอร์กลางเดือน (counter reset) → ผลต่างติดลบ → clamp 0 → ฟรีทั้งเดือน · reading เดือนละครั้ง → 0 ด้วย
**แก้แล้ว:** `usageFromRows()` segment-aware — baseline = reading สุดท้ายก่อน from (ครอบคลุมหน่วยคาบเกี่ยวขอบเดือน + เคส reading เดียว), delta<0 = จับ reset นับ segment ใหม่จาก 0. readings chart route ใช้ helper เดียวกัน (ไม่โชว์ติดลบ). เทส e2e 6/6 ผ่าน (reset กลางเดือน 800→950→0→40 = 190 ไม่ใช่ 0)

### ✅ PIPE-1 · [แก้แล้ว 2026-08-04] ts เป็น ISO string / epoch-string → เพี้ยนเป็นปี 1970 แล้วโดน TTL ลบทิ้งเงียบ
`services/ingest.js` — เดิม string ts: Date.parse(ms)/1000 แต่คูณ 1 → วินาทีถูกอ่านเป็น ms
`"2026-08-02T10:00:00Z"` → 1970 · epoch string → Invalid Date · API ตอบ ok:true แต่ reading หาย (TTL 90 วันลบ)
**แก้แล้ว:** `parseTs()` แยก number sec/ms, string ตัวเลขล้วน (epoch), string ISO (Date.parse) + guard เวลา<ปี2000→fallback now. เทส e2e ผ่าน (ISO/epoch-string/number ทุกแบบเก็บ ts ปีถูก) · **ยืนยันบน production**: ยิง ISO ts ผ่าน public URL → เก็บ 2026-08-02T10:00Z ถูก
