## ✅ สิ่งที่ต้องทำในซอฟต์แวร์

1. **`site.cutoff_enabled = false`** — ปิดตายระดับไซต์ ไม่ใช่แค่ซ่อนปุ่มใน UI (กันสั่งพลาด)
   - API `/api/units/[id]/control` ต้อง reject ที่ชั้น controller ไม่ใช่แค่ UI
2. **`site.type = condo | residential_rental`** → ล็อกเรทไม่ให้เกินเรทการไฟฟ้า/ประปาที่ตั้งไว้
3. **บิลต้องแสดงจำนวนหน่วยที่ใช้** (ประกาศกำหนด) — ตรวจว่า [`06-billing.md`](../../platform/06-billing.md) รองรับ
4. **มิเตอร์ส่วนกลาง** (`meter.kind = common_area`) — ลิฟต์ / ปั๊ม / ไฟทางเดิน + น้ำ เพื่อกระจายค่าส่วนกลางตามจริง
5. ตัด logic **auto-cutoff เมื่อค้างชำระ / prepaid หมด** ออกสำหรับไซต์ประเภทนี้ → เปลี่ยนเป็น**แจ้งเตือน + ออกใบแจ้งหนี้**แทน
