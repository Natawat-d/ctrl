## ⭐ [common/](common/) — ใช้ร่วมกัน

ทั้ง 2 สายผลิตภัณฑ์ใช้ **มิเตอร์ตัวเดียวกัน · โปรโตคอลเดียวกัน (Modbus RTU) · กฎการเดินสาย RS485 เดียวกัน**
ต่างกันแค่ **วิธีส่งข้อมูลกลับ** และ **มี/ไม่มีอุปกรณ์ตัดจ่าย**

| ไฟล์ | เนื้อหา |
|------|---------|
| [system-wiring-design.md](common/system-wiring-design.md) | **คู่มือวิศวกรรมหลัก** — แรงดัน RS485, กฎ daisy-chain/termination, connector, การต่อขั้วทีละตู้, register map, เช็คลิสต์ก่อนจ่ายไฟ |
| [ref_hardware.md](common/ref_hardware.md) | ลิงก์ซื้อของทุกชิ้น + ราคา |

**อุปกรณ์ที่ใช้เหมือนกันทั้ง 2 สาย**

| อุปกรณ์ | รุ่น | ราคา |
|---------|------|------|
| มิเตอร์ไฟ RS485 | DDS238-2 ZN/S · 1P 230V 60A · FC03 · 9600 8N1 | 396 ฿ |
| มิเตอร์น้ำ RS485 | photoelectric direct-reading DN15 | ~1,500 ฿ |
| USB → RS485 isolated | 1 ตัวต่อบัส (กัน surge เข้าเมนบอร์ด) | 350 ฿ |
| สาย RS485 | shielded twisted pair 2×2×0.5 — **A / B / GND 3 เส้นเสมอ** | 25 ฿/ม. |

## 🏪 [market-mesh/](market-mesh/) — ตลาด

- **มีตัดน้ำ-ตัดไฟ** (สัญญาเช่าเชิงพาณิชย์ ทำได้)
- เครือข่าย: **ESP32 mesh (ESP-NOW)** — ดูโปรโตคอลที่ [docs/product/market/01-protocol-mesh.md](../docs/product/market/01-protocol-mesh.md)
- อุปกรณ์ตัดจ่าย: TOMZN TOCT1 2P 63A **2NC** (ไฟ) + Motorized Ball Valve DN15 **NO** (น้ำ)
  → fail-safe: ระบบล่ม = แผงยังมีน้ำมีไฟ

## 🏢 [condo-metering/](condo-metering/) — คอนโด / ที่พักอาศัย

- **ไม่มีตัดน้ำ-ตัดไฟ** — ตัดคอนแทกเตอร์ วาล์ว และบอร์ดรีเลย์ออกทั้งหมด (เหตุผลกฎหมายในหน้าแรกของโปรเจกต์)
- เครือข่าย: RS485 เดินสายตรง — **ตู้มิเตอร์ประจำชั้น** ต่อ daisy-chain ขึ้น-ลง riser
- เพิ่ม: **มิเตอร์ส่วนกลาง** (ลิฟต์ / ปั๊ม / ไฟทางเดิน + น้ำ) เพื่อกระจายค่าส่วนกลางตามจริง
