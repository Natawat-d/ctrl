## อ่านไดอะแกรมยังไง

**สีสาย** (ใช้สีจริงตอนเดินสายให้ตรงกัน)

| สี | ความหมาย |
|----|----------|
| ⬛ ดำ/น้ำตาล | L — ไฟ 220 VAC |
| 🟦 ฟ้า | N — นิวทรัล |
| 🟩 เขียว-เหลือง | PE — กราวด์ |
| 🟥 แดง | +24 V DC |
| ⬜ เทา | 0 V DC |
| 🟨 เหลือง | RS485 **A (D+)** |
| 🟩 เขียวน้ำทะเล | RS485 **B (D−)** |
| ⬜ เทาอ่อน | RS485 **GND common** |
| 🟧 ส้ม | 220 VAC ขับคอยล์คอนแทกเตอร์ / วาล์ว |
| 🟪 ม่วง | (สำรอง — ไม่ใช้ในดีไซน์ปัจจุบัน) |

**บัส RS485** วาดเป็นเส้นหนา 2 สี — 🔵 น้ำเงิน = บัส 1 (ไฟ, COM1) · 🟣 ม่วง = บัส 2 (น้ำ, COM2)
เส้นหนา 1 เส้นในผังรวม = **สายจริง 3 เส้น (A / B / GND)** เสมอ

**สัญลักษณ์**
- ▪️ สี่เหลี่ยมเล็กมีตัวเลข/ตัวอักษร = **ขั้วต่อจริงบนอุปกรณ์** (ขันสกรูตรงนั้น)
- ⬤ จุดดำบนเส้น = **ต่อถึงกัน** (สายไขว้กันโดยไม่มีจุด = ไม่ได้ต่อกัน)
- 🟧 `120Ω` = ตัวต้านทาน termination คร่อม A-B — ใส่เฉพาะ **2 ตัวที่ปลายสุดของแต่ละบัส**

## ⚠️ สถานะการตรวจสอบขั้วต่อ (สำคัญ)

ในแผ่น 1 มีตาราง **"ขั้วต่อที่ใช้ในผังนี้ — สถานะการตรวจสอบ"** แยกชัดว่าอันไหนยืนยันแล้ว อันไหนต้องเช็คเอง

**✔ ยืนยันจากเอกสารผู้ผลิตแล้ว**
- **Waveshare Modbus RTU Relay 16CH** — silkscreen `RS485_A` / `RS485_B` · ไฟเลี้ยง `7~36V` + `GND` · หน้าสัมผัส **1NO+1NC ต่อช่อง** (NO/COM/NC) ≤10A 250VAC/30VDC · default **9600** · addr 1–255
  คำสั่งเปิดรีเลย์ช่อง 1: `01 05 00 00 FF 00 8C 3A` · ปิด: `01 05 00 00 00 00 CD CA` · เปลี่ยน address: FC `06` เขียน register `0x4000`
- **DDS238-2 ZN/S register map** (จากคู่มือผู้ผลิต) — อ่านด้วย FC `03`, เขียนด้วย FC `10`
  `0x0000`(2) Total kWh ×0.01 · `0x0008`(2) Export · `0x000A`(2) Import · `0x000C` V ×0.1 · `0x000D` A ×0.01 · `0x000E` W ·
  `0x0010` PF ×0.001 · `0x0011` Hz ×0.01 · `0x0015` ID+baud (byte1=ID, byte2: 01=9600 02=4800 03=2400 04=1200) · default **9600 None-parity**
- **TOMZN TOCT1 2P** — โพล 1-2 / 3-4 · คอยล์ A1-A2 (IEC/EN 61095)

**⚠️ ต้องยืนยันกับของจริงก่อนเดินสาย**
- **ขั้ว 1/2/3/4 ของ DDS238-2** — คู่มือระบุเองว่าให้ยึด **แผนผังที่พิมพ์บนฝาครอบขั้ว** เป็นหลัก (ในผังใช้ 1=L in, 2=L out, 3=N in, 4=N out ซึ่งเป็นเลย์เอาต์ที่พบทั่วไป)
- **ตำแหน่งขั้ว RS485 A/B ของมิเตอร์ไฟ** — แยกจากขั้วกำลัง ต้องดูของจริง
- **มิเตอร์น้ำ RS485** — สีสาย/แรงดันไฟเลี้ยง (12V หรือ 24V) และ register ต่างกันทุกยี่ห้อ **ต้องขอเอกสารจากผู้ขายก่อนสั่งล็อต**
- **พิน RS485 บน DB9 ของ Mini PC** — ใช้เป็นตัวสำรองเท่านั้น แต่ถ้าจะใช้ต้องวัดยืนยัน (pin 1/2/5 หรือ 3/4/5)
