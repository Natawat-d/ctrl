## 🖥️ สถาปัตยกรรม: gateway ประจำชั้น + แยกเครือข่ายไฟ/น้ำ

```
Mini PC 4×LAN ── LAN0 ──► Router / ISP
              ── LAN1 ──► switch ไฟ ──┬─► RS485→LAN ชั้น 1 (192.168.10.11) ══ Power Meter addr 1–16
              │                       ├─► RS485→LAN ชั้น 2 (.12)           ══ addr 17–32
              │                       └─► RS485→LAN ชั้น 3 (.13)           ══ addr 33–48
              ── LAN2 ──► switch น้ำ ─┬─► RS485→LAN ชั้น 1 (192.168.20.11) ══ custom board addr 121
                                      ├─► ชั้น 2 (.12) ══ addr 122
                                      └─► ชั้น 3 (.13) ══ addr 123
```

- **เครือข่ายไฟกับน้ำแยกกันทางกายภาพ** — คนละ switch คนละ subnet (10.x / 20.x) ระบบหนึ่งล่มไม่ลากอีกระบบ
- **แต่ละชั้นมี RS485→LAN ของตัวเอง** — RS485 จบในชั้น (≤16 node ไม่กี่เมตร) **ไม่มีบัสยาวข้ามชั้น ไม่มีปัญหา 32 UL** · riser เป็น Cat5e
- poll: subnet เลือกระบบ → IP เลือกชั้น → Unit ID เลือกอุปกรณ์ · **ทุกชั้นทุกระบบวิ่งขนานกัน**
- surge จากสายในชั้นจบที่ gateway (750 ฿) — Ethernet มี magnetic isolation กัน Mini PC อยู่แล้ว

| อุปกรณ์ | รุ่น | ราคา |
|---------|------|------|
| Mini PC | **4×LAN Intel N2940 / Pentium J5005** 4 คอร์ fanless ([ลิงก์ที่เลือก](https://th.aliexpress.com/item/1005012371146843.html)) | **3,262.72 ฿** (ราคาจริงจากหน้าสินค้า) + RAM 550 + SSD 700 — แนะนำสั่งรุ่น **J5005** แรงกว่า N2940 ~2 เท่า |
| RS485→LAN ประจำชั้น | **Waveshare RS485 TO ETH (B)** · DIN · 6~36V | ~750 ฿ × (2 ตัว/ชั้น) — ทางเลือก: USR-TCP232-304 ~900 ฿ |
| Switch | Gigabit 5 port ×2 (ไฟ/น้ำ) | 450 ฿/ตัว |
| สาย LAN riser | Cat5e | 12 ฿/ม. |

> 💡 ฝั่งน้ำ gateway ต่อ custom board แค่ตัวเดียว/ชั้น — ถ้าอยากลดต้นทุน เปลี่ยน custom board เป็นรุ่นมี Ethernet ในตัว (ESP32 + W5500 ~150 ฿) คุย Modbus TCP ตรง ตัด gateway น้ำออกได้ชั้นละ 750 ฿

**เหตุผล:** คอนโด/ที่พักอาศัยตัดน้ำ-ไฟไม่ได้ตามกฎหมาย (ดูหน้าแรกของโปรเจกต์) → อุปกรณ์ตัดจ่ายกลายเป็นของที่ซื้อมาแล้วใช้ไม่ได้ และสร้างความเสี่ยงทางกฎหมายถ้ามีใครสั่งพลาด

## ✅ สิ่งที่เพิ่มเข้ามา

- **มิเตอร์ส่วนกลาง** — ไฟ 3 จุด (ลิฟต์ / ปั๊ม / ไฟทางเดิน) + น้ำ 1 จุด เพื่อกระจายค่าส่วนกลางตามการใช้จริง
- **ตู้มิเตอร์ประจำชั้น** แทนตู้ใหญ่รวม — สายเมนสั้นลงมาก (สาย 2.5 mm² 45 ฿/ม. แพงกว่าสาย RS485 เกือบ 2 เท่า)
- **คำนวณจำนวนบัสอัตโนมัติ** — คอนโดมี 2 มิเตอร์/ห้อง (ไฟ+น้ำ) และ 1 บัสรับได้ปลอดภัย ~24 node → เพิ่ม USB-RS485 isolated ตามจำนวนบัส

## 🏗️ โครงสร้างการเดินสาย

```
ชั้น 8 ── ตู้มิเตอร์ชั้น 8 (16 ห้อง) ──┐
ชั้น 7 ── ตู้มิเตอร์ชั้น 7 (16 ห้อง) ──┤   RS485 daisy-chain
  ⋮                                    ├── ขึ้น-ลง riser
ชั้น 1 ── ตู้มิเตอร์ชั้น 1 (16 ห้อง) ──┤
                                       └──► ตู้ Main (ห้องนิติ / ห้องไฟฟ้า)
```

RS485 เหมาะกับ riser มาก — daisy-chain ตามชั้นได้ตรง ๆ ระยะสูงสุด 1,200 ม. เหลือเฟือแม้ตึกสูง

## ⚠️ สิ่งที่ต้องทำในซอฟต์แวร์

1. `site.cutoff_enabled = false` — **ปิดตายระดับไซต์** ไม่ใช่แค่ซ่อนปุ่มใน UI (กันสั่งพลาด)
2. ถ้า `site.type = residential_rental` → **ล็อกเรทไม่ให้เกินเรทการไฟฟ้า/ประปา** และบิลต้องแสดง**จำนวนหน่วยที่ใช้** (ประกาศ คกก.ว่าด้วยสัญญาฯ 2562 กำหนด)
3. เพิ่ม meter ประเภท `common_area` เพื่อกระจายค่าส่วนกลาง
