## 🔴 สถานะ: BOM ปัจจุบันเป็นแบบเดินสาย ยังไม่ได้แปลงเป็น mesh

BOM/PDF ในโฟลเดอร์นี้ออกแบบไว้ตอนที่คิดว่าตลาดจะเดิน RS485 ยาวกลับตู้กลาง
พอเปลี่ยนเป็น **ESP32 mesh** โครงสร้างเปลี่ยนไปพอสมควร — **ต้องแก้ก่อนใช้ยื่นราคาจริง**

### ✅ ส่วนที่ใช้ต่อได้เลย (ไม่เปลี่ยน)

อุปกรณ์ระดับแผงเหมือนเดิมทุกชิ้น เพราะยังเป็น Modbus RTU เหมือนกัน:

| อุปกรณ์ | ราคา | หมายเหตุ |
|---------|------|----------|
| มิเตอร์ไฟ RS485 DDS238-2 ZN/S | 396 ฿ | register map ยืนยันจากคู่มือแล้ว |
| มิเตอร์น้ำ RS485 DN15 | ~1,500 ฿ | photoelectric direct-reading |
| TOMZN TOCT1 2P 63A **2NC** | 233 ฿ | fail-safe: คอยล์ไม่มีไฟ = แผงมีไฟ |
| Motorized Ball Valve DN15 **NO** | 718 ฿ | fail-safe: ไม่มีไฟ = น้ำไหล |
| MCB 1P 32A | 90 ฿ | |
| MDR-60-24 | 450 ฿ | |

รวมทั้งกฎการเดินสาย RS485, connector, ferrule, termination 120Ω — ใช้ตามคู่มือใน `common/` ได้ทั้งหมด

### 🔄 ส่วนที่ต้องเปลี่ยนเป็น mesh

| | เดิม (เดินสาย) | ใหม่ (ESP32 mesh) |
|---|---|---|
| Master | Mini PC เป็น Modbus master ของทั้งตลาด | **ESP32 แต่ละโหนดเป็น master ของมิเตอร์ตัวเอง** (RS485 stub สั้น ๆ ในตู้) |
| ส่งข้อมูล | RS485 trunk ยาวกลับตู้กลาง (25 ฿/ม.) | **ESP-NOW multi-hop** ไป gateway — ไม่ต้องลากสายสัญญาณข้ามตลาด |
| Gateway | — | ESP32 gateway 1 ตัว/ตลาด → bridge เป็น MQTT เข้า Mini PC |
| บอร์ดรีเลย์ | Waveshare 16CH RS485 (1,570 ฿/16 แผง) | **อาจตัดทิ้ง** — ให้ ESP32 ขับรีเลย์/opto ตรง ๆ ประหยัดได้มาก |
| USB-RS485 isolated ×2 | 700 ฿ | ไม่ต้องใช้ (ไม่มีบัสยาว) |
| เพิ่มใหม่ | — | **ESP32 node + กล่อง + PSU ต่อแผงหรือต่อกลุ่มแผง** |

### ❓ คำถามที่ต้องตอบก่อนทำ BOM mesh

1. **1 ESP32 คุมกี่แผง?** — 1 โหนด/แผง (ยืดหยุ่นสุด แพงสุด) หรือ 1 โหนด/4–8 แผง (ประหยัด แต่โหนดตายกระทบหลายแผง)
2. **ESP32 ขับคอนแทกเตอร์ตรง หรือผ่านบอร์ดรีเลย์?** — ขับตรงประหยัด 1,570 ฿/16 แผง แต่ต้องออกแบบวงจร opto + รีเลย์เอง
3. **ไฟเลี้ยงโหนด** — ดึงจากแผงนั้น (ตัดไฟแผง = โหนดดับ ❌) หรือจากวงจรควบคุมแยก (ถูกต้องกว่า)
4. **ระยะ hop จริงในตลาด** — ESP-NOW Long-Range ทะลุผนัง/หลังคาสังกะสีได้แค่ไหน ต้องวัดหน้างาน

> รุ่นบอร์ดที่จะใช้เป็นบอร์ด Waveshare ที่มีชิป **ESP32** อยู่แล้ว → เขียนเฟิร์มแวร์ ESP-NOW เองได้ตามโปรโตคอลที่ออกแบบไว้แล้วใน [01-protocol-mesh.md](../../docs/product/market/01-protocol-mesh.md) (binary packet 12B header + AES + short-id 2B + ACK)

## ⚡ ตรรกะตัดจ่าย (fail-safe) — ยืนยันแล้ว

| สถานะรีเลย์ | คอยล์ A1-A2 | หน้าสัมผัส NC | แผงค้า |
|-------------|-------------|---------------|--------|
| OFF (ปกติ) | ไม่มีไฟ | ปิด | ✔ มีไฟ |
| ON (สั่งตัด) | 220 VAC | เปิด | ✘ ไฟดับ |
| โหนดดับ / mesh ขาด | ไม่มีไฟ | ปิด | ✔ **มีไฟ** |

⚠️ **สั่งของให้ถูก:** TOCT1 2P 63A ต้องเป็นรุ่น **2NC** เท่านั้น ถ้าได้ 2NO มาตรรกะจะกลับด้าน → ระบบล่ม = ไฟดับทุกแผง
วิธีเช็ค: วัดความต่อเนื่องขั้ว 1-2 ตอนไม่จ่ายไฟคอยล์ → **ต้องต่อกัน**
