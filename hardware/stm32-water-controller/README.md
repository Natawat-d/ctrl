# ⭐ ตู้ควบคุม STM32H743 — ตู้น้ำ + ตู้ไฟ

ตัวนับ/อ่านมิเตอร์แบบ **self-contained** ใช้ **STM32H743VIT6** — เก็บลง SD + มี LAN/RS485/LCD ในตัว
(แทนแนวทางเดิม Mini PC + gateway · ดู [../old_structure/condo-metering](../old_structure/condo-metering))

## 2 ตู้ (โครงเดียวกัน ต่างที่ opto)
| อุปกรณ์ | ตู้น้ำ | ตู้ไฟ |
|---|:---:|:---:|
| STM32H743VIT6 + microSD | ✅ | ✅ |
| Custom PCB | ✅ | ✅ |
| **Optocoupler Isolation 16CH** (in24V→out3.3V) | ✅ | ❌ ตัดออก |
| LAN W5500 | ✅ | ✅ |
| TTL→RS485 | ✅ | ✅ (มิเตอร์ไฟ Modbus) |
| LCD 16×4 | ✅ | ✅ |
| PSU 24V + 5V | ✅ | ✅ |

**ตู้ไฟ** = เหมือนตู้น้ำ แต่ตัด opto — เพราะมิเตอร์ไฟ (DDS238) เป็น **RS485 Modbus** ต่อผ่าน RS485 module ไม่ใช่พัลส์

## ยังไม่รวม / ทำทีหลัง
- **Sensor ไฟ** (มิเตอร์ DDS238 RS485) — เพิ่มทีหลัง
- **ตัวตู้ enclosure + terminal + เบ็ดเตล็ด** — เอาออกแล้ว (จะสเปกตู้จริงทีหลัง)

## หมายเหตุ
- opto 16CH: input 24V → output 3.3V เข้า GPIO STM32 ตรง = 16 มิเตอร์น้ำพอดี
- ไม่มี PSU 3.3V — STM32 core board reg 3.3V ในตัว (เลี้ยง 5V)
- มิเตอร์น้ำ 2หุน: ระบุ **K-factor (พัลส์/ลิตร)** ตอนสั่ง
- เฟิร์มแวร์ (เขียนเอง): นับพัลส์ + debounce + เซฟ SD + ส่งค่าออก LAN (REST/Modbus TCP)
